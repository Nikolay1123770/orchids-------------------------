# SMG VPN - Инструкция по установке и запуску

## Описание

Полнофункциональное VPN-приложение с оплатой через ЮMoney и реальным VPN-подключением через VLESS протокол.

## Возможности

- Регистрация и авторизация пользователей
- Подписка с оплатой через ЮMoney (50₽/месяц, 150₽/3 месяца, 300₽/6 месяцев, 600₽/год)
- Автоматическая активация подписки после оплаты
- Реальное VPN-подключение через VLESS WebSocket
- Статистика трафика
- Несколько серверов (в настоящий момент: Франкфурт, Германия)

## Требования

- Node.js 18+
- Bun или npm
- Доступ к 3x-ui панели (уже настроен: 213.176.77.13:2053)

## Запуск

### 1. Запуск Backend

```bash
cd backend
npm run dev
```

Backend запустится на порту 3002.

### 2. Запуск Frontend (в отдельном терминале)

```bash
cd frontend
npm run dev
```

Приложение откроется в Expo.

### 3. Запуск с ngrok туннелем (для реального устройства)

```bash
cd backend
npm run dev:tunnel
```

Это автоматически:
- Запустит backend
- Создаст ngrok туннель
- Обновит .env.local во frontend

Затем в другом терминале:

```bash
cd frontend
npm run dev
```

## Как работает оплата

1. Пользователь выбирает тариф в разделе "Подписка"
2. Нажимает "Оплатить" → открывается ЮMoney
3. Оплачивает на странице ЮMoney
4. ЮMoney отправляет webhook на `/api/payment/webhook`
5. Backend проверяет подпись и активирует подписку
6. Пользователь может подключиться к VPN

## Как работает VPN

1. После оплаты подписки пользователь нажимает кнопку "ПОДКЛЮЧИТЬ"
2. Backend создает/обновляет клиента в 3x-ui панели
3. Возвращает VLESS URL: `vless://UUID@213.176.77.13:443?type=ws&path=/api...`
4. Пользователь копирует ссылку в v2rayNG/NekoBox или использует встроенное подключение

## API Endpoints

### Auth
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Профиль

### Подписка
- `GET /api/plans` - Список тарифов
- `POST /api/payment/create` - Создать платеж
- `GET /api/payment/status` - Проверить статус оплаты
- `POST /api/payment/webhook` - Webhook от ЮMoney

### VPN
- `POST /api/vpn/connect` - Подключиться (требует подписку)
- `POST /api/vpn/disconnect` - Отключиться
- `GET /api/vpn/traffic` - Статистика трафика
- `GET /api/vpn/status` - Статус сервера

## Troubleshooting

### Backend не запускается
- Проверьте, что порт 3002 свободен
- Убедитесь, что установлены все зависимости

### Frontend не подключается к Backend
- Проверьте `EXPO_PUBLIC_BACKEND_URL` в `.env.local`
- Убедитесь, что backend запущен

### VPN не подключается
- Проверьте, что есть активная подписка
- Убедитесь, что 3x-ui панель доступна
- Проверьте логи backend на наличие ошибок

### Оплата не проходит
- Проверьте правильность YOOMONEY_TOKEN и YOOMONEY_WALLET
- Убедитесь, что webhook URL доступен из интернета (используйте ngrok)
